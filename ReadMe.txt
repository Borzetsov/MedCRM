Сервис CRM для медицинских центров

Назначение
Сервис предназначен для автоматизации работы медицинских учреждений.
Сервис представляет собой WEB-приложение, доступное в сети Интернет.
Сервис позволяет автоматизировать:
- регистрацию и учет пациентов;
- запись пациентов на прием;
- ведение медицинской карты пациента;
- составление графика рабочего времени врачей;
- расчет стоимости медицинских услуг.
